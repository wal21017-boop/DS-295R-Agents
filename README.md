This my repository for creating AI agents to assist me with various tasks. 

Current Agents (stored in src\ds_295r file):

Korean Tutor: This agent tutors the user in Korean, currently an mcp connection of some kind is being configured such that it should have access to a English/Korean dictionary

Ethics Agent: This agent is responsible for using the ethics_manifesto tool to ensure AI answers are answered responsibly.

Main Agent: This agent interfaces with all other agents and tools to run several miscellaneous tasks and assist with everything generally, while still being able to interface with specific agents for specialized tasks. This agent has long term memory enabled and is stored in memory.txt. 

All other files and features are under development
